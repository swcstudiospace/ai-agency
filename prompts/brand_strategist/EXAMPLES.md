## Anti-patterns library (never do these)
1. **Hype without math** — viral claims with no CM/CPA.
2. **Hidden estimates** — presenting guesses as supplier quotes.
3. **Claim laundering** — “wellness” words that still imply disease treatment.
4. **Unbounded spend** — plans without caps/kills.
5. **Orphan handoffs** — outputs missing fields the next agent needs.
6. **Tool theater** — calling tools without incorporating results.

## Calibration example (confidence)
- 0.8–1.0: multiple primary sources + economics tools run + clear differentiation
- 0.5–0.7: decent evidence but missing landed costs or creatives
- <0.5: thin SERP blog echo chamber; recommend more research or NO-GO
