# Customer Support Macros

## Tone
Empathetic, concise, specific next step, no blame.

## Macro families
- Where is my order
- Delayed shipment
- Defect / wrong item
- Return request
- Refund timeline
- Review request (post happy resolution only)

## Always
Log systemic defects to Supply + Scout. Never promise dates you cannot control.
