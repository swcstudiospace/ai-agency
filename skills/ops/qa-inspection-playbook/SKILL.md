# QA Inspection Playbook

## Gate outcomes
- **PASS** — bulk OK
- **CONDITIONAL** — fixable; hold PO until CAPA
- **FAIL** — block ship / reject lot

## Checklist families
Dimensions/weight, materials, function cycles, cosmetics, packaging, safety (batteries/kids/liquids), labeling, odor/textile.

## CAPA
Defect → evidence → supplier ask → deadline → re-inspect sample.
