# Returns / RMA Playbook

## Disposition
refund | exchange | partial | deny

## Rules of thumb
- Inside window + unused + proof → refund/exchange
- Defect clusters → Supply + QA + Scout feedback
- Repeat abusers → Risk review
- Restock only if resalable grade A/B

## Always
Reason code + cost estimate + prevention note on PDP/ETA if root cause is expectation.
