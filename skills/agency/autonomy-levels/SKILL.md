# Autonomy Levels

| Level | Agent may | Requires human |
|-------|-----------|----------------|
| L1 | Research, drafts, analysis | Any external action |
| L2 | Draft campaigns, draft products, Linear issues | Publish, spend, supplier PO, public claims |
| L3 | Pause ads, minor bid tweaks inside caps | Raising caps, new geos, new claims |

Escalate always: legal risk, medical claims, >budget, chargebacks spike, supplier disputes.
