# ROAS Guardrails

## Autonomy
- **L1 observe**: recommendations only
- **L2 draft**: create plans/campaigns as drafts; human approves spend
- **L3 bounded auto**: pause losers / raise winners inside pre-set caps
Default agency mode: **L2**

## Floors (set per account; example)
- Learning kill: ROAS < 1.0 after 1.5× target CPA spend
- Scale: ROAS ≥ target for 3 consecutive days and CM positive
- Daily cap: Finance Controller sets; Growth may not exceed without approval

## Structure
- CBO vs ABO per skill paid-social-structure
- Always attach kill criteria and creative refresh cadence in Linear
