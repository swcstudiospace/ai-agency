# Linear Ops

## When to create issues
Strong product candidates, campaign launches, compliance BLOCKs, supplier shortlists, weekly scorecards.

## Title patterns
- `[Scout] {product} — score {n} — {GO|TEST|NO-GO}`
- `[Growth] {campaign} — {status}`
- `[Compliance] BLOCK — {asset}`
- `[Supply] Supplier shortlist — {SKU}`

## Description must include
Objective, evidence links (Parallel), numbers (CM/ROAS), decision, next action, owner team.
