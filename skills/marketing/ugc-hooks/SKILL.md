# UGC Hooks

## Hook types (first 1–3s)
1. Problem call-out
2. Pattern interrupt visual
3. Contrarian claim (compliance-safe)
4. Social proof cold open
5. POV “I didn’t expect…”

## Angle bank
- Speed / convenience
- Before/after (no medical)
- Giftability
- Travel / compact
- Value vs premium alternative

## Deliverable per concept
Hook line, on-screen text, spoken script (15s/30s), CTA, primary visual, compliance notes.
