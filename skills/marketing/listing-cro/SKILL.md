# Listing CRO

## Above the fold
Benefit-led title, price clarity, primary image = product in use, trust badges that are true.

## Structure
1. Outcome-led intro
2. 5 bullets (benefit → feature)
3. Social proof
4. How it works
5. Specs
6. FAQ / objections
7. Shipping/returns honest ETAs

## Image order
Hero in-use → detail → scale → unboxing → lifestyle → proof.

## Never
Fake scarcity, unverifiable reviews, medical claims, bait pricing.
