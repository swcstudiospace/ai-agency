# Paid Social Structure

## Testing matrix
- 3–5 hooks × 2 bodies × 2 CTAs (or fewer if budget tight)
- Isolate one variable per test cell when possible

## Account structure (default)
- Prospecting campaign (broad + interest stacks as needed)
- Retargeting separated
- Creative testing sandbox with strict daily cap

## Fatigue
Refresh when frequency↑ and CTR/CPA worsen 3+ days. Request Creative Team batch, don’t scale stale winners blindly.
