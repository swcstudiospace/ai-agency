# AI Dropshipping Agency Docs

Welcome to the operator manual for the **Hermes x Agno** dropshipping control plane.

## What this system is

A virtual company of **30 specialized agents** that:

1. **Discover** products (Parallel Web + SuperGrok research)
2. **Locate** suppliers (automated sourcing shortlist)
3. **Build** brand, creatives (PromptWise/Fal), Shopify drafts
4. **Grow** with Meta/TikTok drafts + HITL spend vault
5. **Operate** returns, fraud, logistics, tax, experiments

Default autonomy is **L2**: aggressive research/drafting; humans approve money and live publish.
