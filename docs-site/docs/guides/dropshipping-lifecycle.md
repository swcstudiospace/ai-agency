# Dropshipping lifecycle

1. Discover — niches to ranked SKUs
2. Locate — suppliers + landed cost
3. Validate — samples, QA
4. Brand — positioning, claims gate
5. Create — PromptWise/Fal UGC, listings
6. Store — Shopify draft
7. Launch — ad drafts then HITL spend
8. Fulfill — logistics, CX, returns
9. Learn — KIP memory, weekly review
